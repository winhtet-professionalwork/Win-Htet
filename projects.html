Smart Solar Drip Irrigation System

Project Type: Senior Engineering Capstone

Focus: Smart Agriculture, Sensors, Automation, and Renewable Energy

Project Overview

This project focuses on developing a low-cost, solar-powered smart drip irrigation system for sustainable agriculture.

The system uses soil moisture sensors to monitor soil conditions at different locations in a garden. An Arduino collects sensor measurements and communicates with a Raspberry Pi, which supports data processing and a web-based monitoring platform.

System Components

  • Solar power system
  • Capacitive soil moisture sensors
  • Arduino microcontroller
  • Raspberry Pi 3 Model B
  • Web-based monitoring dashboard
  • Drip irrigation and water pump control system

My Responsibilities

  • Wireless communication and system integration
  • Sensor data acquisition and monitoring
  • Technical control system development
  • Web-based data visualization
  • Data-based irrigation decision support

Project Goals

The goal is to develop an affordable and practical irrigation system that uses soil moisture data to support efficient water management and sustainable agricultural practices.

Applying PageRank Algorithms to Analyze Diplomatic Connectivity Among Nations

Period: 2025–2026

Research Area: Applied Mathematics and Computational Analysis

This undergraduate research project focused on applying the PageRank algorithm to analyze diplomatic connectivity among G20 nations. I developed and implemented the PageRank algorithm using MATLAB and constructed directed graph models to represent diplomatic relationships among nations. Through this research, I investigated the convergence properties of iterative numerical algorithms and applied concepts from linear algebra, probability, and graph theory to study network connectivity. I also presented my research findings at an undergraduate research seminar.
